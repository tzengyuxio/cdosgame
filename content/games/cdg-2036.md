《德軍總部》（Wolfenstein 3D）是 id Software 於 1992 年 5 月推出、由 Apogee Software 以共享軟體（shareware）形式發行的第一人稱射擊遊戲，為德軍總部系列第三作。玩家扮演波蘭裔美籍間諜 B.J. Blazkowicz，從納粹的沃夫斯坦城堡監獄脫逃，在關卡中射殺守衛與軍犬、蒐集武器與補給，逐章推進，最終與身披機械戰甲的希特勒對決<sup class="cite" data-ref="wikipedia"></sup>。本作由 John Carmack 打造的光線投射（ray casting）引擎驅動，能在當時有限的硬體上快速渲染擬 3D 空間；它被譽為「3D 射擊遊戲的祖父」，奠定並普及了第一人稱射擊類型，也為 id Software 隔年的《毀滅戰士》鋪路<sup class="cite" data-ref="wikipedia"></sup>。

遊戲採共享軟體發行，首章免費散布、其餘章節付費，幾乎憑一己之力證明了這套模式的商業可行性。因大量納粹符號，本作曾自 1994 年起在德國遭禁售，直到 2019 年才解禁。台灣由[精訊資訊](/companies/精訊)引進，編號 D020，以英文原版磁片流通<sup class="cite" data-ref="wikipedia"></sup>。

id Software 同年 9 月另推出獨立前傳《命運之矛》（Spear of Destiny），由 FormGen 發行。故事設定於本傳之前，B.J. Blazkowicz 奉命奪回納粹從凡爾賽宮掠走的命運之矛，即傳說中刺穿耶穌的朗基努斯之槍；本作沿用 Wolfenstein 3D 的引擎與玩法，是可獨立執行的完整遊戲，FormGen 其後又於 1994 年推出《Return to Danger》與《Ultimate Challenge》兩部任務包<sup class="cite" data-ref="wikipedia"></sup>。命運之矛是否曾在台灣單獨發行並不明確——精訊的產品編號僅見於本傳（D020），未見命運之矛的獨立編號。
