《杏林也瘋狂》（Theme Hospital）是英國 Bullfrog Productions 開發、Electronic Arts 發行的醫院經營模擬遊戲，原版 1997 年 3 月推出，同時提供 MS-DOS 與 Windows 執行環境<sup class="cite" data-ref="wiki-th-en"></sup>。繁體中文版由[美商藝電](/companies/美商藝電)代理，2001 年 3 月在台上市<sup class="cite" data-ref="bahaacg-th"></sup>。中國大陸另以《主題醫院》之名流通<sup class="cite" data-ref="wiki-th-zh"></sup>。

玩家接手一間私人醫院，規劃診間與走廊動線、採購設備，並雇用醫生、護士、維修工與櫃檯接待四類人員，在資金與聲望的關卡目標下逐步擴張。病症全屬虛構的搞笑疾病，如頭部膨脹的「膨脹頭」與自認是貓王的「貓王症候群」，每種病都要先投入研究才能開發療法，經營途中還得應付疫情爆發與急診湧入<sup class="cite" data-ref="wiki-th-en"></sup>。美術總監 Gary Carr 表示刻意避開真實疾病，一來創作空間較大，二來不願拿真實病痛開玩笑<sup class="cite" data-ref="wiki-th-en"></sup>。

本作是 Bullfrog 繼 1994 年遊樂園經營作 Theme Park 之後的「Theme」系列第二作，最初構想由 Peter Molyneux 提出，但他因忙於《地下城守護者》而未實際參與製作；遊戲全球銷量逾四百萬套<sup class="cite" data-ref="wiki-th-en"></sup>。原班人馬後來另組 Two Point Studios，於 2018 年推出精神續作《雙點醫院》<sup class="cite" data-ref="wiki-th-en"></sup>。
