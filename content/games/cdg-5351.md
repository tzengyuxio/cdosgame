《辛巴達幻境奇航》（Sinbad in the Lost Land，全名《辛巴達幻境奇航～千里尋爺記》）是捷友資訊科技於 1996 年 4 月推出的中文冒險遊戲<sup class="cite" data-ref="chronicle"></sup>。題材取自《一千零一夜》的辛巴達航海傳說，鋪陳為阿拉伯風格的奇幻大冒險。五十年前，老辛巴達在亞特絲浮島群與三位賢者合力將惡法師翟斯帕克封入幻之獄，法力鎖在鎮魔寶典之中；五十年後，惡法師的寵貓迪多洛帶著幻滅水晶液穿越時空前來復仇，將祖孫二人一併捲入浮島群。玩家操縱小辛巴達往返沙浮島、森林浮島、光浮島、夢浮島與岩石浮島，尋訪勇氣之士可瑞歐斯公爵、仁慈之母凱德莉亞女巫與智慧之父威斯丹尼爾主教，湊齊四項寶物重新啟動平衡之心；全劇分為六大段落<sup class="cite" data-ref="swm81"></sup>。

本作在開發時被稱為國產遊戲中唯一純粹的 Windows 95 圖形冒險遊戲，以 Windows 95 內建的 WING 模組與 Game SDK 為程式基礎，畫面為 640×480、256 色<sup class="cite" data-ref="swm81"></sup>。操作採類似《國王密使七》的點選式滑鼠介面，玩家只要看到目標就能點選互動。捷友並請專業人員錄製對白與音效，使其成為國內第一款全程配有中、英文雙語語音的遊戲，約二十首配樂則以音軌形式燒錄在光碟上；也因資料量龐大，僅製作 Windows 光碟版<sup class="cite" data-ref="swm81"></sup>。發行前一年的雜誌廣告以「國內首次自製冒險遊戲」為號召，列出十餘段全螢幕動畫、數十首配樂與上千頁的劇情動畫做為賣點；同一版面下方另刊有美術設計的徵才啟事<sup class="cite" data-ref="swm80ad"></sup>。原先預定 1996 年初上市，實際發行時間又延後了數月。捷友資訊此後轉往棋牌與休閒題材，陸續推出《WIN麻將96NET》（1996）、《[三國麻將風雲](/games/cdg-0259)》與《[藍調情人](/games/cdg-5155)》（1998）、《[熱血躲避球](/games/cdg-3312)》（2000）等作，2000 年代初再有《[野蠻世紀之恐龍戰士](/games/cdg-1333)》與《[傲世蒼龍之趙雲傳](/games/cdg-1667)》<sup class="cite" data-ref="chronicle"></sup>。
