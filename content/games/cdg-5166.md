《蒼鋼騎兵》（Space Griffon VF-9）是日本 Panther Software 開發的第一人稱機甲射擊遊戲，台灣由雄圖資訊代理發行盒裝版。

玩家駕駛可於步行與行駛型態間變換的巨大機甲，在月球上的機密設施中作戰，遊戲揉合射擊與迷宮探索的角色扮演要素，並以大量 CG 過場動畫串接劇情<sup class="cite" data-ref="wikipedia"></sup>。原作 1995 年於 PlayStation 首度推出，1999 年以《蒼鋼の騎兵》之名重製登上 Dreamcast，2000 年再推出 Windows 版；台灣代理版即移植自此一 Windows 版本。台灣版隨附中文操作說明書，遊戲本體則維持日文。
