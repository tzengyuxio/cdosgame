《龍王三國正史》是日本廠商龍（RON）製作的三國題材戰略遊戲，台灣由[美商藝電](/companies/美商藝電)代理發行<sup class="cite" data-ref="cgw169"></sup>。產品以兩片光碟合售，內容其實是兩款各自獨立的遊戲——《三國正史》與《龍王三國演義》，因此中文版包裝以合稱行銷，系統需求為 Pentium 等級以上機種與 Windows 95，音樂採 PCM 音源而非 CD 音軌<sup class="cite" data-ref="cgw169"></sup>。

兩作性質差異甚大。《三國正史》偏向帶戰略成分的冒險遊戲，玩家選擇扮演曹操、孫權或劉備其中一人，時間在遊戲中持續流動，隨進程觸發該主角專屬的歷史事件；重要戰役可選擇旁觀或親自操作戰棋式的戰鬥，遊戲速度亦可調整<sup class="cite" data-ref="cgw169"></sup>。《龍王三國演義》則是與《三國志》系列同性質的君主養成戰略遊戲，但改採即時制而非回合制。其官職系統將武將分派為武官與各府文職，共十四階；設有參謀府（分軍師與情報局兩種職能，後者用於偵知武將出走與叛變）、兵工廠（研發士兵的盔甲與武器）等機構，並可在首都自由興建城牆、房屋，遊戲中不設金錢概念。徵兵固定在每年四月一日與十月一日，兵力多寡取決於城鎮人口，命令傳達則透過「快馬」派遣；全作收錄約八十個歷史事件，並開放武將臉譜、能力與特殊能力的自訂編輯<sup class="cite" data-ref="cgw169"></sup>。

當時評論對本作評價保留。報導稱兩片光碟的安裝程序皆易失敗，畫面雖僅二百五十六色但美術水準尚可，最大問題在中文化品質——戰鬥單挑時會出現未翻譯的日文整句、部分中文字溢出對話框，並將翻譯不盡理想列為主要缺點<sup class="cite" data-ref="cgw169"></sup>。

## 版本

- **《昇龍三國志》**：《龍王三國演義》的前身，早三年推出、以 DOS/V 為平台；報導稱中文版為該作改為 Windows 95 版後易名重出<sup class="cite" data-ref="cgw169"></sup>。
