《毀滅戰士》（Doom）是 id Software 於 1993 年推出的第一人稱射擊遊戲，玩家在火星基地與地獄惡魔交戰，透過高速移動、武器切換與迷宮探索推進關卡。本作沿用共享軟體（shareware）模式發行：第一章免費散布，玩家付款註冊後再以郵寄取得其餘兩章<sup class="cite" data-ref="pcgamer_romero"></sup>。它是 1990 年代 PC 動作遊戲的代表作，推動了網路連線對戰、關卡模組與 FPS 類型的普及。

台灣由[精訊](/companies/精訊)取得 id Software 正式授權代理，以盒裝英文版發行，產品編號 D023。精訊與 id 的合作始於前作[《德軍總部》](/games/cdg-2036)：據徐社長的說法，精訊人員先接觸該作的共享軟體版，主動聯繫 id 爭取代理，並曾赴達拉斯拜訪 id；其後續代《毀滅戰士》與[《毀滅戰士2》](/games/cdg-1920)<sup class="cite" data-ref="retrogametime_rebuttal"></sup>。銀狐則在留言中指出，精訊實際想談的是《毀滅戰士》，《德軍總部》當時早已在網路上廣泛流傳、難以獲利，是隨《毀滅戰士》綁在一起授權的<sup class="cite" data-ref="fn01"></sup>。

2026 年，id Software 共同創辦人 John Romero 在 QuakeCon 座談中談及共享軟體的散布策略時表示，id 當年知道本作在台灣被大量拷貝，於是主動聯繫當地最大的盜版商，以極低價格賣給對方大量遊戲盒，讓其販售的拷貝看來合法；對 id 而言那只是一種通路，收入仍來自玩家訂購完整版<sup class="cite" data-ref="pcgamer_romero"></sup>。此說經媒體轉載後在台港引起關注，但台灣遊戲媒體資深人士徐社長隨即撰文反駁：台灣早在 1992 年 6 月施行新著作權法，本作上市時市面公開販售的盒裝盜版已近絕跡；精訊並非當年最大的盜版商，玩家所購得的是完整授權的盒裝正版；經向參與代理的精訊人員查證，亦無向 id 購買空盒之事，推測是 Romero 記憶有誤<sup class="cite" data-ref="retrogametime_rebuttal"></sup>。
