《新三國演義99》是業訊於 1999 年推出的三國題材戰略遊戲，以中文版於台灣發行，屬於同時期眾多取材自《三國演義》的國產戰略作品之一。遊戲原生於 Windows 9x 環境開發，收錄於單張光碟，是 1990 年代末台灣中小型軟體業者投入歷史戰略類型的產物。

由於發行規模有限、留存資料稀少，本作的具體玩法與製作陣容多已不可考。其原生於 Win9x 時代的特性，使得在 Windows XP 之後的系統上執行需將主程式設為 Win9x 相容模式，也反映出這款作品所處的早期 Windows 過渡年代。
