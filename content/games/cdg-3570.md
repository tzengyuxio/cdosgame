《瓊斯博士視窗大冒險》（Indiana Jones and His Desktop Adventures）是 LucasArts 於 1996 年推出的 Windows 冒險遊戲，台灣由[松崗](/companies/松崗)代理中文化發行，支援 Windows 3.1 與 Windows 95。遊戲以印第安納·瓊斯為主角，在小品式、可隨機生成的關卡中探索、解謎與尋寶，是最早一批專為 Windows 桌面環境設計的輕量冒險遊戲之一。
