《橫掃千軍》（Total Annihilation）是美國 Cavedog Entertainment 於 1997 年推出的即時戰略遊戲，也是[橫掃千軍](/games/cdg-3232)系列的開山作。故事設定在遙遠未來，銀河因意識上傳的存亡之爭而分裂為堅持機械化的 Core 與捍衛肉身的 Arm 兩大陣營，雙方展開長達數千年、幾近同歸於盡的戰爭；玩家擇一陣營，指揮一部可自我複製生產線的「指揮官」機甲，從無到有建立軍隊席捲戰場。

本作在當時以技術規格突破同儕：單位採 3D 建模並具備真實的彈道物理與地形高低差，戰場可同時容納數百個單位廝殺，並支援自訂單位與地圖。相較於同期《魔獸爭霸》《終極動員令》以少量精銳單位運籌，《橫掃千軍》強調大規模鋼鐵洪流與後勤生產，資源系統改採金屬與能量兩種可持續流量而非囤積式採集，深受策略社群推崇，其開放的模組架構也讓玩家自製內容延續多年。Cavedog 隨後推出《核子風雲》（The Core Contingency）與《武力反擊》（Battle Tactics）兩款資料片，1999 年並將本體與資料片合輯為《指揮官包》發行。台灣市場流通英文版，由美商新美代理引進<sup class="cite" data-ref="wikipedia"></sup>。台灣版盒裝雖為英文內容，包裝卻做了中文化：封面英文標題下印有中文「橫掃千軍」，封底文案全篇中文，並把兩大陣營譯為「核心」與「武力」，是 Core 與 Arm 當年的官方中譯。盒側標示產品編號 04-12523，平台為 Windows 95 CD-ROM，封面另印設計者 Chris Taylor 之名與 E3 GamePen's Best of E3 獎項標章。續作為改採奇幻題材的[橫掃千軍2：改朝換代](/games/cdg-3232)。

## 版本

- **《核子風雲》（The Core Contingency）資料片**：Cavedog 推出的資料片，須在《橫掃千軍》主程式下執行，台灣同由美商新美代理。新增二十五個由原創意小組設計的任務與一個玩家級特別任務、七十五種陸海空作戰單位，其中包含具毀滅與報復性的柯古斯機甲（Krogoth），並附地圖與任務編輯器；多人連線提供五十餘張為二至十人設計的地圖，最大地圖達 64MB<sup class="cite" data-ref="cgw169ad"></sup>。
