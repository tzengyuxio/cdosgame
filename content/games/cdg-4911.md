《約翰尋腦記》（Monty Python's Flying Circus: The Computer Game）是英國 Core Design 開發、Virgin Games 發行的橫向捲軸射擊遊戲，改編自英國喜劇團體 Monty Python 的電視節目《Monty Python's Flying Circus》。家用電腦各版於 1990 年推出，MS-DOS 版則於 1991 年問世<sup class="cite" data-ref="wikipedia"></sup>。

玩家操控節目中的招牌角色「Mr. Gumby」穿越多屏場景，以飛腳、丟魚等超現實手段攻擊各式怪誕敵人，過程穿插大量 Monty Python 式的無厘頭橋段。台灣由[智冠科技](/companies/智冠)旗下副品牌歐風軟體（Europhone）以英文原版引進。
