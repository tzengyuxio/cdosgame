# 廠商遺珠紀錄

本檔記錄「與中文 PC 遊戲史相關、但整體不納入本站遊戲條目正本」的廠商與作品群。用途是保留考據脈絡，避免日後重複調查；不代表作品沒有史料價值。廠商大致依成立或主要活動起始年代排序。

## 瑪吉斯 MAXXIS

瑪吉斯科技是正新橡膠轉投資的 3D 賽車遊戲公司。MoneyDJ 2002 年新聞記載，瑪吉斯科技成立於民國 89 年 5 月（2000 年 5 月），主要開發即時運算 3D 賽車遊戲，資本額 0.36 億元，其中正新出資 0.33 億元、持股約九成，是正新當時唯一非本業投資的子公司。其遊戲資料多以「瑪吉斯」「瑪吉斯科技」或「瑪吉斯 MAXXIS」署名，題材集中在賽車、越野車與自行車競速。

### 不收錄原因

瑪吉斯科技成立於 DOS 時代之後，已知作品也都是 Windows 競速遊戲，與 DOS 遊戲難以建立直接關聯。因此不建立正式公司頁；相關作品保留在遺珠紀錄中，作為 2000 年代初台灣 3D 競速遊戲脈絡參考。

## 大正系統

大正系統（大正系統股份有限公司）是 2000 年代初台灣 Windows 光碟遊戲的發行／總代理商。依 2004 年 Wayback Machine 保存的「大正系統已發行之遊戲軟體簡介」頁，該公司頁面列出的遊戲多由網巨科技研發、大正系統總代理，類型集中在親子向、休閒動作與益智遊戲。頁尾署名公司地址為「臺北市忠孝東路五段 669 號 9 樓之 2」，並列 TEL `(02)8785-0039`、FAX `(02)8785-0031`。

### 不收錄原因

大正系統這批作品的發行時間皆在 2000 年之後，且資料來源列示平台均為 Windows。本站目前以 DOS 時代中文 PC 遊戲為主；這批作品屬 post-DOS Windows 休閒遊戲群，和 DOS 主範圍距離較遠，因此不建立正式遊戲條目與公司頁。若未來另開「2000 年代台灣 Windows 休閒遊戲」專題，可再回頭評估。

## 朔太科技

朔太科技在資料中常以「朔太」或「朔太科技」出現，是 2000 年代前半台灣 Windows PC 遊戲廠牌。上一輪調查未查到可核實的官網存檔或完整公司沿革；可確認的作品集中在戀愛養成、女性向戀愛劇情養成與成人向麻將／戀愛題材，常見規格為 1CD、Windows 或 WinXP。青衫之友清單另有《麻將小魔女》《麻雀奇緣金瓶梅》列為朔太科技，並有《淘氣鬼闖通關大富翁》標作「兔兔米（朔太）」，顯示「朔太」可能也作為較短廠牌名或關聯標記使用。

### 不收錄原因

朔太科技成立於 2004 年，主要活動與 DOS 遊戲無關。即使資料中可見部分「朔太」署名早於 2004 年，現有來源仍指向 2000 年代 Windows 遊戲流通脈絡，而非 DOS 時代中文 PC 遊戲廠商。因此不建立正式公司頁；相關遊戲也維持在遺珠／待考脈絡中，不納入 DOS 主範圍。

## 未來數位

未來數位成立於 2006 年 4 月，是 2000 年代後的台灣遊戲發行／代理相關廠商。本站目前只記錄其作為後 DOS 時代廠商的排除判斷，不整理遊戲年表。

### 不收錄原因

未來數位成立時間已在 DOS 時代之後，主要活動與 DOS 遊戲無關。因此不建立正式公司頁，也不針對該公司整理發行年表；若未來另開 2000 年代 Windows 或成人向／日系代理專題，再視專題範圍評估。
