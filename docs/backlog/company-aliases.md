# 公司別名 / 改名 → redirect 候選

## 觀念釐清（重要）

兩種情況要分開看：

- **純別名**（同一家公司、只是名字寫法不同：簡繁、全名/簡稱、中英）——已由各公司 md 的
  `aliases` 欄位涵蓋（供搜尋/辨識）。**通常不需要 redirect**，因為不會有人去連舊寫法的網址。
- **改名 / 先後傳承**（兩個都是正式名、有承接關係，但不想開兩頁、想保留關係）——這才用
  redirect 合成一頁。範例：**世紀縱橫 → 貳碼科技**（已啟用）。

→ redirect 精選表 `src/lib/company-aliases.js` **只收第二類**。加一筆 = redirect + 別名發行的
遊戲自動歸 canonical 頁（兩處同步）。

## 現況

**先全部保留、延後處理**。等累積更多遊戲資料（看是否有遊戲以舊名/別名發行、是否確有改名傳承
需要保留關係）再回來挑要做哪些。

- [x] 世紀縱橫 → 貳碼科技（已啟用）
- [x] Kogado / Kogado Studio → 工畫堂（已啟用）。例外：屬中英純別名而非改名傳承，破例進精選表是因 9 款原以 Kogado 入庫、外部 DB（MobyGames 等）亦用此名，redirect 有實益。
- [x] KSK / Kure Software Koubou / 吳氏工房 / 吳氏工坊 → 呉ソフトウェア工房（已啟用）。同上之多寫法純別名；3 款原各以 KSK／Kure Software Koubou／吳氏工坊 三種名入庫，canonical 取日文正名（無通行中文正名）。

## 待評估的傳承/改名候選（有了更多資料再判斷）

- [x] 富進 / 富優 / 富峰群 → 遊戲橘子（Gamania）：已釐清為連續改名史（富進軟體工作室 → 富優＋富峰群 1995 並立、1997 合併 → 富峰群資訊 → 1999 遊戲橘子）。採貳碼科技模式：三個前身名只做 redirect（`COMPANY_ALIASES`）、無獨立頁，內容併入 `遊戲橘子.md` 沿革，遊戲頁保留當時廠名。
- [x] 河洛工作室 ↔ 東方演算：**決議兩者分開、不登記 alias（2026-07-15，使用者裁決）**。
  - **理由：不適用本表的 alias→canonical 模型**。河洛之名橫跨前後兩期（cdg-1706 封神演義 1998；cdg-1626/1627 俠客風雲傳 2015/16），東方演算僅 2001–2006 中間段。任一方向登記都會錯置歸屬——`河洛工作室→東方演算` 會把 2015/16 作品掛到 2006 已解散的公司名下；`東方演算→河洛工作室` 則抹掉東方演算作為 cdg-5140 當時廠名的獨立性。關係已由 cdg-5140 正文敘述（含維基＋百度雙來源），無需 redirect。
  - 沿革（供參）：河洛 1993 成立、原屬智冠開發組 → 《武林群俠傳》後徐昌隆帶隊脫離另立東方演算 → 《三國群俠傳》2002 為其首作 → 2006 解散 → 原成員 2014 重組復用河洛之名推出《俠客風雲傳》《俠隱閣》。
  - ⚠ **兩者皆為台灣公司**（百度百科：「东方演算是台湾的一家游戏公司」）。曾一度以「東方演算跨台灣到大陸、組成差異大」為分開的理由，該說法**經使用者更正為誤**，已撤回；cdg-5140 `developer_region: TW` 正確無需改。

## 注意

- 精選表**不要**塞會撞到既有公司頁 id 的別名（會蓋掉那頁），程式無額外防呆。
- 同一別名只能指一個 canonical。
