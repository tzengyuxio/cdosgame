## 待釐清問題

- KudGame 的「【晟業】手談」是否誤把豐海《手談》歸到晟業，或其實指晟業／智冠《初段手談》。
- 「圍棋封神榜」是否為晟業實際產品、別名、或清單誤植；目前本地資料與外部搜尋都未能對應。
- 「中國陸軍棋」是否為晟業產品；目前只找到智冠《陸軍棋》與新造科技《決戰陸軍棋》等近似項，未找到晟業同名條目。
- 2003 年以後的晟業／智冠棋侶系列是否要納入資料庫，或歸入廠商遺珠／排除清單。
- `Win31/XP`、`Win31/95/XP` 類作品是否因支援早期 Windows 而可納入，或仍應依 DOS 主範圍排除。
